## 3. SECTION 1.4 — WHAT "ASSESSED FROM THE RECORDS" ACTUALLY DOES

**A firm that appears only in an NCR log can now set A4.8's band, and through A4.8 the Document
Signals category and the project status. This is real and it is the largest behaviour change in
the run.** The code names it on the reading rather than leaving it to be discovered:

> "ACROSS FIRMS THE MOST ADVERSE ADJUSTED POSTURE GOVERNS — Run 115's rule, unchanged. A firm
> carrying trade records and NO stated rating is assessed from those records and can therefore
> govern, which is a real behaviour change: an unrated firm appearing only in an NCR log can now
> set this module's band, and through it the Document Signals category and the project status."

Mechanically:

1. `_trade_postures(si, rated)` builds a posture for every firm in `set(by_firm) | set(rated)`.
   A firm in the records but not in `rated` gets `starting_band = None`.
2. `_trade_only_reading(si)` is the **trade-records-alone** path, taken when **no** performance
   report states a rating for any firm. It is called from **two places** — before
   `require_v4_structure` raises `StructureAbsent`, and after the rating-bearing path — because a
   project with no subcontractor performance report at all never reaches `require_v4_structure`,
   and a path that existed only after it would have been **unreachable on exactly the projects
   §1.4 is about.** The second attempt measured it unreachable and lifted it out.
3. **The Run 107 PM review hold applies identically.** An Amber or Red posture reached this way is
   `pending_pm_review` and asserts no band, "because Run 107's hold is a property of the POSTURE,
   not of where it came from, and exempting this path would be a quiet way of letting an
   unreviewed Red out."
4. The audit record records `source_rating: "none stated"` and
   `"No rating was stated for any firm here, so none was altered."`
5. **Where the records produce no factor band either, the module goes on abstaining.** Nothing is
   invented to fill the gap.

**WHAT MAKES A ROW UNUSABLE:**
- **Not an object** → unusable, counted in `denominator_rows_unusable`.
- **No firm name, or a blank one** → **unusable.** "A denominator naming no firm is unusable, not
  'the project's'. It cannot be attributed and it is never spread across firms."
- A **value that will not parse as a finite number** → that **column** is skipped; the rest of the
  row still counts. Nothing is defaulted to zero.
- A row that parses no column at all contributes nothing and its document is not recorded as a
  source.

**THE RULE, on the record as `denominator_rule`:** *"a denominator is a number the document counts.
It is never derived from how many attribution rows arrived, never carried over from another firm
and never defaulted. Where a firm has records and no denominator, no rate is formed and only the
hard overrides apply. Denominators for the same firm on several documents are **SUMMED per
column**, never averaged and never overwritten."* Which documents contributed is kept per firm in
`denominator_source_document_types`, so the sum can be taken apart again.
