### 2.2 THE RECONCILIATION THE BRIEFING ASKED FOR — what "total float on the controlling path" means

**The float band is only meaningful against an IMPOSED finish, and that is how it is implemented.**
The backward pass anchors on the network's own finish, so the controlling path's total float is
**zero by construction** on every valid network with no imposed date. Banding that would take every
project Red and would be measuring the arithmetic, not the schedule. So the float rule is evaluated
against the **imposed or required completion date the export states** — exactly Run 102's reading of
A2.1's override, which section 2.4 says stands and which I did not overturn.

**Where the network states no imposed date, the float rule is NOT EVALUABLE, is not applied, and is
not counted as a pass.** It says so on the row. A non-evaluable rule can never make a project look
better; it simply leaves the other three to govern.

## 9. FOUND AND NOT FIXED — the largest finding of this run

**A category posture does not reflect an adverse module reading, and the mechanism is a manufactured
independence declaration.**

Measured on the census project, on the real stored bands:

```
A6 bands as stored          : {"A6.1":"Green","A6.2":"Green","A6.3":"Green","A6.4":"Amber"}
A6 category posture (stored): "Green"
```

and on A2, `A2.1` is **Red** while the A2 category publishes **Green**, `status_set_by` naming only
A2.8, A2.9 and A2.12.

`fusion.fuse_signals`'s own docstring states the safeguard: *"AN UNDECLARED SIGNAL IS NEVER
INDEPENDENT BY DEFAULT … an undeclared RED signal would then make the fusion read GREENER than the
evidence in hand."* Called directly with the real lineage records, that safeguard works — A6 fuses to
**Amber**, because `lineage.lineage_for("A6.1"…"A6.4")` returns **`None`** for all four, so they land
in one unresolved body and the idempotent worst-of operator governs.

But `qualification_gate.qualify()` **synthesises an empty lineage record** for a module that declares
none, and `QualifiedSignal.to_fusion_signal()` hands that record to the fusion. Four modules with no
declared lineage therefore become **four independent bodies**, Dempster's rule combines three Greens
